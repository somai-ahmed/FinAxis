# Getting Started

## 1. Prerequisites

| Tool | Version | Used for |
|---|---|---|
| Python | ≥ 3.10 | Desktop app |
| CMake | ≥ 3.16 | Building the C engine |
| C compiler | C11 (GCC, Clang, MSVC) | Engine |

Python packages (`requirements.txt`): `PySide6>=6.6`, `openpyxl>=3.1`, `pytest>=8.0`.

## 2. Install

```bash
git clone https://github.com/somai-ahmed/FinAxis
cd FinAxis
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Build the native engine

```bash
cd Src/FinCore.Native
cmake -S . -B build
cmake --build build --config Release
```

Output: `build/FinAxis_ae.dll` (Windows) or `build/FinAxis_ae.so` (Linux). The engine links `libm` on non-MSVC compilers.

Native tests (when the `tests/native/` folder exists):

```bash
cmake -S . -B build -DFINCORE_BUILD_TESTS=ON
cmake --build build
ctest --test-dir build
```

Test targets: `test_utils`, `test_comptes`, `test_ecritures`, `test_balance`, `test_detection`, `test_persistence`.

## 4. Run the desktop app

```bash
cd Src/FinAxis.Desktop
python main.py
```

On startup you choose: **new company**, **open a `.FinAxis` file**, or **demo data** (generated by `services/demo_data.py`).

## 5. Library lookup order

`bindings/finaxis_ffi.py` searches, in order:

1. Path in the `FINCORE_DLL` environment variable
2. PyInstaller bundle (`sys._MEIPASS`)
3. `Src/FinCore.Native/build`, `build/Release`, `build/Debug`, `.`

```bash
export FINCORE_DLL=/full/path/to/FinAxis_ae.so      # Windows: set FINCORE_DLL=C:\...\FinAxis_ae.dll
```

## 6. Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| CMake: "No SOURCES given" / empty library | `FINCORE_SOURCES` vs `FINAXIS_SOURCES` | See [known_issues.md](known_issues.md) #1 |
| CMake: cannot find source file | Paths differ from repo layout | Known issues #2 |
| `ModuleNotFoundError: bindings.fincore_ffi` | File is `finaxis_ffi.py` | Known issues #4 |
| "FinCore_ae introuvable" dialog | Library name mismatch | Known issues #3, or set `FINCORE_DLL` |
| `AttributeError: FinCore_Version` | Exported name is `finAxis_Version` | Known issues #5 |
